# C题统一术语与符号表

| 中文术语 | 英文/符号 | 定义 | 单位或范围 | 使用约束 |
|---|---|---|---|---|
| 无创产前检测 | NIPT | 通过母体血浆游离DNA进行染色体筛查 | 无 | 筛查不等于确诊 |
| 检测孕周 | `t` | `周+天/7`换算的连续孕周 | 周 | 不与抽血次数混用 |
| 身体质量指数 | BMI | 体重/身高米数平方 | kg/m² | 分组变量，不等同体重 |
| Y染色体浓度 | `Y_ij` | 男胎记录中Y染色体游离DNA片段比例 | 0—1 | 4%写为0.04 |
| 达标 | `Y≥0.04` | 题面定义的NIPT基本准确条件 | 0/1 | 不是胎儿健康标签 |
| 首次达标时间 | `T_i` | 孕妇Y浓度首次达到4%的孕周 | 周 | 可为左/区间/右删失 |
| 达标概率 | `F_i(t)` | `P(T_i≤t|x_i)` | 0—1 | 不是异常诊断概率 |
| 随机截距 | `u_i` | 混合模型中的孕妇个体效应 | logit尺度 | 处理重复检测相关性 |
| 记录级误差 | `ε_ij` | 同一孕妇不同检测记录的剩余误差 | logit尺度 | 与测量误差模拟区分 |
| 标准化孕周 | `W` | `(t-mean(t))/sd(t)` | 标准差单位 | 系数不直接表示每周变化 |
| 标准化BMI | `B_ij`/`B_i` | 问题1使用第`j`次记录BMI；问题2、3使用孕妇记录BMI中位数，再标准化 | 标准差单位 | 两种层级不可混用，系数不直接表示每1 kg/m²变化 |
| 线性混合模型 | LMM | 固定效应加孕妇随机截距的纵向模型 | 无 | 问题1主模型 |
| 似然比检验 | LRT | 比较嵌套模型对数似然差 | p值 | 只检验整体增量 |
| Wald检验 | - | 固定效应系数除以标准误的显著性检验 | p值 | 不等同因果检验 |
| 区间删失 | interval censoring | 首次达标只知道位于两次检测之间 | 周区间 | 不能用区间中点冒充真值 |
| AFT模型 | Accelerated Failure Time | 直接建模达标时间分布的生存模型 | 无 | 问题2、3主预测模型 |
| 外层测试折 | outer test fold | 只用于无偏评价的未见孕妇集合 | 无 | 禁止参与调参和分组搜索 |
| 内层验证折 | inner validation fold | 用于早停、参数和政策选择 | 无 | 同一孕妇必须同折 |
| OOF预测 | out-of-fold prediction | 样本未参与该模型训练时得到的预测 | 0—1 | 用于公平政策搜索 |
| Optimal Binning | 全局最优分箱 | 在有序BMI候选切点上搜索连续分组 | 无 | 不是单棵决策树 |
| 有序动态规划 | ordered dynamic programming | 枚举连续分段并求给定候选空间全局最优 | 无 | 不保证候选空间外全局最优 |
| 开发安全裕量 | 95% development target | 训练OOF阶段用于抵御部署误差的较高阈值 | 比例 | 与部署90%可靠性区分 |
| 部署可靠性 | 90% deployment target | 推荐周前组内平均达标概率要求 | 比例 | 由外层测试审计 |
| 保守下限 | LCB | 达标概率的不确定性下界 | 0—1 | 用于安全判定 |
| 政策组可靠性 | - | 按最终BMI政策分组计算的组内均值或LCB | 0—1 | 回答推荐政策自身是否安全 |
| 四分位审计层安全性 | - | 按外层训练集BMI四分位切成四层后的最低均值或LCB | 0—1 | 比政策组更细的压力测试，问题3为均值4/4、LCB 3/4折 |
| 准确性损失 | `R_a` | `1-mean[F_i(t_i)]` | 0—1 | 越小表示推荐周达标概率越高 |
| 连续等待损失 | `R_t` | `mean[clip((t_i-13)/14,0,1)]` | 0—1 | 仅用于中期内部风险敏感性分析 |
| 不稳定损失 | `R_s` | `1-repeat_fold_safety_rate` | 0—1 | 与抽样和分折波动相关 |
| 患者Bootstrap | patient bootstrap | 以孕妇为单位有放回抽样 | 次数 | 同一孕妇多条记录整体抽取 |
| 重复折安全率 | - | 重复外层测试折中通过安全线的折比例 | 0—1 | 不等同Bootstrap安全率 |
| Bootstrap安全率 | - | Bootstrap样本中政策通过安全条件的比例 | 0—1 | 与重复分折评估不同波动来源 |
| 测量误差标准差 | `σ_e` | 同孕妇同孕周重复Y浓度估计的稳健波动 | 比例 | 约0.003716即0.372个百分点 |
| 状态改变率 | - | 误差扰动后4%删失状态改变的比例 | 0—1 | 不是疾病误诊率 |
| 题面三级风险 | - | ≤12周低、13—27周高、≥28周极高 | 等级 | 中期内部不区分等待周数 |
| 连续等待风险 | - | 假设13—27周内每延后一周风险继续上升 | 相对量 | 仅作为敏感性扩展 |
| 主推荐 | - | 在题面风险口径下通过完整稳定性门槛的政策 | 周 | 问题2、3均为18/22 |
| 敏感性方案 | - | 改变风险函数或误差假设后的备选政策 | 周 | 不与主推荐并列为唯一答案 |
