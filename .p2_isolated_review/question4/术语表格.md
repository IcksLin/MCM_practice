| 特征向量 | Feature vector | x_i | 第i条检测记录进入模型的全部非泄漏特征 | 混合 | 数学模型 | 不包含孕妇代码和标签 |

| 正类权重 | Positive-class weight | α_c | 内层训练折中染色体c阴性数除以阳性数，仅乘正类损失 | 正数 | 目标函数 | 不乘负类损失 |

| 判定阈值 | Decision threshold | t_c | 将概率转换为阳性/阴性的训练期阈值 | 0—1 | 阈值定义 | 不用测试折调节 |
| 阈值距离 | Threshold distance | d_ic | `|p_ic-t_c|` | 0—1 | 复测区定义 | 不称预测误差 |

| Platt校准 | Platt scaling | - | 用内层OOF分数拟合sigmoid概率映射 | 无 | 概率校准 | 不在外层测试标签上拟合 |

| 原始序号 | Source row number | s_i | 附件A列序号，仅用于复测距离并列时稳定排序 | 整数 | 复测区定义 | 禁止作为模型特征 |
| 灵敏度 | Sensitivity / Recall | Se | 阳性记录中被正确检出的比例 | 比例 | 评价指标 | 不称准确率 |
| 特异度 | Specificity | Sp | 阴性记录中被正确排除的比例 | 比例 | 评价指标 | 不称阴性预测值 |
| 阳性预测值 | Positive Predictive Value | PPV | 模型阳性中真实AB阳性的比例 | 比例 | 评价指标 | 不称灵敏度 |
| 阴性预测值 | Negative Predictive Value | NPV | 模型阴性中真实AB阴性的比例 | 比例 | 评价指标 | 不称特异度 |
