# C题精简工程导航

本目录保留问题1—4的可复现代码、冻结结果、证据图和正式报告；已删除被权威入口取代的历史搜索、旧报告和中间产物。

## 问题1—3统一入口

```powershell
python scripts/run_all.py
```

该命令重建问题1、执行问题3嵌套外层独立审计、校验问题2/3冻结结果哈希、重绘9幅证据图，并更新 `results/q123/复现清单.json`。历史大规模搜索不会在默认入口中重复运行。

- `question1/`：纵向混合效应模型，分析孕周、BMI及交互项与Y染色体浓度的关系。
- `question2/`：区间删失 AFT、全局 Optimal Binning、固定政策比较与稳健性审计。
- `question3/`：多因素增益检验、BMI有序分组与无外层选参嵌套审计。
- `question123/`：统一运行、绘图、清单与统合报告生成代码。
- `results/q1|q2|q3|q123/`：当前有效的精简结果与冻结参数。
- `figures/q123/`：问题1—3的原始数据、建模过程和结论证据图。
- `doc/`：仅保留问题1—3统合报告与问题4正式报告。
- `工作框架/`：患者表、固定折号与通用数据固化工具。

## 当前结论口径

- 问题1：孕周与Y浓度正相关、BMI负相关，孕周×BMI交互未达显著。
- 问题2：主推荐为 BMI<34.357 第18周、BMI≥34.357 第22周；16/18仅为连续风险权重敏感性结果。
- 问题3：便于解释的固定政策为 BMI<35 第18周、BMI≥35 第22周。该结论是全数据开发后的内部稳定性建议，不是无偏独立测试结论；嵌套外层审计用于报告其泛化边界。
- 所有建议仅用于数学建模与研究性分流，不构成临床诊断或处置意见。

问题4仍由 `question4/`、其结果与图件以及 `doc/C题问题4最终报告_v5.docx` 独立维护。
