# C题固定验证协议

版本：1  
冻结日期：2026-08-24

## 1. 目的

本协议固定问题2/3和问题4的数据单位、交叉验证折号、调参边界和评价指标。后续统一时点、两组、三组、经验五组及其他候选方案必须使用相同外层测试折，禁止为了提高结果重新选择随机划分。

## 2. 数据版本

- 唯一数据源：`data/raw/附件.xlsx`。
- 数据身份以 `数据清单.json` 中的 SHA-256 为准。
- 原始附件不做原地修改；所有派生标签由固化脚本重新生成。

## 3. 男胎问题2/3

### 3.1 标签构造

1. 同一孕妇、同一孕周的重复检测取 Y 染色体浓度中位数。
2. 首次观测已经达到4%：左删失 `[0, upper]`。
3. 先未达标、后达标：区间删失 `[lower, upper]`。
4. 最后一次仍未达标：右删失 `[lower, +∞)`。

### 3.2 数据划分

- 每名孕妇只保留一条患者级删失记录。
- 外层4折按删失类型分层，作为测试折。
- 每个外层训练集内部固定3折，作为调参和早停验证折。
- 每名孕妇在每一层只能属于一个折。

### 3.3 特征边界

允许使用检测前可获得的 BMI、年龄、身高、体重、IVF、孕次和产次。禁止将同次检测后才能获得的 Z 值、GC、读段质量或 X/Y 浓度作为时点推荐输入。

### 3.4 指标

- 第一预测指标：外层 AFT 负对数似然。
- 辅助预测指标：区间一致性、预测落入观测区间比例。
- 第一决策指标：外层 OOF 预期风险。
- 辅助决策指标：平均检测孕周、推荐时点未达标概率、组数复杂度及bootstrap稳定性。

## 4. 女胎问题4

- 训练单位为检测记录，划分单位为孕妇。
- T13、T18、T21分别固定4个外层测试折。
- 每个外层训练集分别固定3个内层折。
- 同一孕妇的全部记录不得跨折。
- 第一指标为患者级 PR-AUC；辅助指标为 ROC-AUC、Brier、校准和至少90%灵敏度下的特异度。
- AB列是附件检测输出复核标签，不等同于真实临床诊断终点。

## 5. 训练、验证、测试角色

| 数据部分 | 用途 | 是否允许影响参数 |
|---|---|---|
| 外层训练折 | 拟合候选模型 | 是 |
| 内层验证折 | 超参数搜索、早停、模型选择 | 是 |
| 外层测试折 | 生成OOF预测、比较方案 | 否 |
| 全样本 | 评估完成后训练交付模型 | 仅使用已确定方案 |

任何外层测试指标都必须来自该折完全未参与调参时的预测。全样本模型不再声称具有独立测试成绩；正式泛化指标来自外层OOF预测。

## 6. 变更控制

如果后续确需改变标签规则、折数、随机种子、评价指标或特征边界，必须：

1. 新增协议版本，不覆盖本版本；
2. 重新生成折号和数据清单；
3. 所有候选方案在新协议下全部重跑；
4. 报告变更原因及对结论的影响。
