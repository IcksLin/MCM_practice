# C题问题4题目分析报告

## 1. 题目与附件清单

- 题目：2025年高教社杯全国大学生数学建模竞赛C题《NIPT的时点选择与胎儿的异常判定》，问题4。
- 原题：`C题/C题.pdf`，2页。
- 原始附件：`data/raw/附件.xlsx`，SHA-256为`14827156218bd4f7e4f16db4aa6d9f757c6648379e038ae6c6b58383648614af`，保持只读。
- 目标工作表：`女胎检测数据`，原始有效数据为605条检测记录、147名孕妇、31列。
- 结论边界：附件AE列“胎儿是否健康”在女胎数据中605条均为“是”，不能作为真实疾病结局训练或外部验证。本题只能学习并复现AB列记录的T13、T18、T21非整倍体筛查判定，不能声称诊断胎儿疾病。

## 2. 问题拆解与结论目标

问题4要求利用女胎的X染色体及13、18、21号染色体Z值、GC含量、读段数量和比例、BMI等信息，给出异常判定方法。最终需要输出：

1. 每条女胎检测记录属于T13、T18、T21的概率及多标签判定；
2. “任一非整倍体异常”的总风险和正常/异常结论；
3. 传统Z值阈值与多因素模型在未见孕妇上的对比；
4. 灵敏度、特异度、阳性预测值、阴性预测值、F1、F2、ROC-AUC、PR-AUC及概率校准结果；
5. 对低质量或模型不确定记录给出“建议复测”，而不是强制二分类；
6. 明确内部验证、类别不平衡、重复检测和标签不是出生结局等限制。

## 3. 数据理解

### 3.1 标签结构

AB列空白视为本次检测未发现T13/T18/T21异常。将组合标签拆成三个二元标签：

- T13：23条记录、18名孕妇；
- T18：46条记录、30名孕妇；
- T21：13条记录、12名孕妇；
- 任一异常：67条记录、44名孕妇；正常：538条记录。

组合标签包括T13T18、T13T21和T18T21，因此必须使用多标签判定，不能将6种字符串直接当成互斥多分类。

### 3.2 重复检测与泄漏风险

147名孕妇平均有4.12条记录，最多9条。同一孕妇的多次检测共享年龄、身高、妊娠方式等信息。若按记录随机划分，训练集和测试集可能同时包含同一孕妇，导致性能虚高。因此外层与内层验证均按`孕妇代码`分组，同一孕妇只能出现在一个折中。

### 3.3 特征与缺失

纳入特征：

- 染色体信号：13、18、21、X染色体Z值，X染色体浓度；
- 染序质量：总读段数、唯一比对读段数、比对比例、重复比例、被过滤比例、总GC及13/18/21号染色体GC；
- 孕妇特征：年龄、身高、体重、BMI、孕周、IVF、孕次、产次、抽血次数；
- 构造特征：三个目标染色体Z值绝对值、最大绝对Z值、Z值间差异、唯一比对读段占比、GC偏离量、BMI缺失指示。

排除特征：序号、孕妇代码、检测日期、末次月经和AE列。它们可能引入身份、时间批次或结局泄漏，不作为预测变量。

BMI仅缺失1条，必须在每个训练折内用中位数填补，并加入缺失指示。两个女胎空白列全为空，直接删除。IVF为类别变量，在训练折内编码。

## 5. 数学模型

### 5.1 多标签定义

令染色体集合为`C={13,18,21}`。对第i条记录，标签定义为：

`y_ic = 1`，当且仅当AB字符串包含`Tc`。

三个分类器分别估计：

`p_ic = P(y_ic=1 | x_i)`。

任一异常概率采用概率并集：

`p_i(any) = 1 - ∏_{c∈C}(1-p_ic)`。

该式用于风险排序；最终多标签仍由各染色体阈值分别决定，避免高发T18掩盖稀有T13和T21。

### 5.2 代价敏感XGBoost

对每个染色体c，最小化带类别权重和患者等权的二元对数损失：

`L_c = -Σ_i v_i [α_c y_ic log(p_ic) + (1-y_ic)log(1-p_ic)] + Ω(f_c)`。

其中，孕妇g有`m_g`条记录时，`v_i=(1/m_g)/mean_j(1/m_{g(j)})`，避免多次检测孕妇支配损失；`α_c=n_negative/n_positive`只作用于正类项。在每个内层训练折中单独计算`v_i`和`α_c`，内层验证标签不参与；选定参数后才在完整外层训练集重新计算。树深、学习率、子采样率和正则化强度在内层分组交叉验证中选择，主评分为PR-AUC，辅以F2和校准误差。

### 5.3 阈值与复测区

超参数选定后，用同一参数重新生成完整内层OOF原始概率。采用Platt sigmoid校准：以这些OOF原始分数和标签拟合单变量逻辑回归校准器，再作用于完整外层训练模型产生的外层测试原始概率。若内层OOF阳性少于8条、阴性少于20条或校准器数值失败，则不拟合Platt映射，后续直接使用XGBoost的原始`predict_proba`概率；阈值、复测带和外层评价流程完全相同。

对每个染色体，在“校准后的内层OOF概率”或上述回退的“原始内层OOF概率”上构造候选阈值：全部相邻唯一概率中点，加上`nextafter(min_probability,-∞)`和`nextafter(max_probability,+∞)`两个端点，因而允许全阳性和全阴性方案。若OOF阳性不少于8条，先保留灵敏度不低于85%的阈值，再选择特异度最高者；特异度并列时依次选择F2最高、阈值最高者。若无可行阈值或阳性少于8条，则选择F2最高者；并列时依次选择灵敏度最高、阈值最低者。该规则唯一且不读取外层测试标签。

为避免把接近阈值的样本强行二分，设不确定带：

`|p_ic - t_c| ≤ δ_c`。

令`d_ic=|p_ic-t_c|`，`δ_c=min(0.15,Q_0.15({d_ic}))`，其中经验分位数采用lower方法。该定义取满足复测比例上限的最大离散带宽；若相同距离造成比例略超过15%，按`(d_ic, 原始序号)`升序，仅标记前`floor(0.15n)`条。原始序号只作为确定性并列键，不进入模型。

测序质量极端由总读段数、唯一比对读段数、比对比例、重复比例、过滤比例和总GC六项确定。所有1%与99%分位点只在相应训练折估计；至少两项越界，或总/唯一读段数低于训练折0.5%分位点，记为质量极端。题面GC低于40%另作质量警告，但不单独强制复测，因为附件大量记录位于40%附近。若任一染色体进入不确定集合或质量极端，则标记“建议复测”，不计作确诊。

### 5.4 传统Z值对照

固定基准使用`|Z_c|≥3`判定对应染色体异常。训练型Z规则在内层OOF标签上，对`|Z_c|`全部相邻唯一值中点及两个`nextafter`端点进行搜索，并使用与主模型完全相同的“灵敏度≥85%后最大化特异度；并列看F2和较高阈值；不足时最大化F2”的规则。传统规则不使用外层测试折调阈值。

## 6. 验证与判优

### 6.1 嵌套患者级交叉验证

- 外层4折：评估未见孕妇；
- 内层3折：特征处理、超参数、概率校准和阈值选择；
- 同一孕妇所有记录始终同折；
- 分折使用固定种子`20250824`的患者级贪心多标签平衡算法。先汇总每名孕妇的记录数、T13/T18/T21阳性记录数和任一异常标记。对指标集合`K={总记录数,T13阳性记录数,T18阳性记录数,T21阳性记录数,任一异常孕妇数}`，分配目标函数为`Σ_fold Σ_k ((n_fold,k-target_k)/(target_k+1))²`，各分量等权。每次重复以种子`20250824+r`在相同稀有度得分内打乱患者，稀有度得分为各阳性标签患者频率倒数之和，再按记录数降序；逐名放入使目标增量最小的折，增量并列取折号最小者。重复`r=0,...,1999`，取满足约束且目标最小的分配，目标并列取按孕妇代码排序后的折号向量字典序最小者。外层要求每折每种染色体至少2名阳性孕妇，内层要求至少1名；若无法满足，外层回退为3折并完整记录，不允许产生无阳性测试折。

### 6.2 指标

- 每个染色体：灵敏度、特异度、PPV、NPV、F1、F2、ROC-AUC、PR-AUC；
- 总体：micro/macro F1、micro/macro PR-AUC、任一异常的灵敏度与特异度；
- 概率：Brier分数和校准曲线；
- 稳定性：按孕妇有放回Bootstrap 2000次，报告核心指标95%区间；
- 判优顺序：先比较宏平均PR-AUC和T13/T21灵敏度，再比较F2、校准和复测率，不用准确率单独判优。
- 任一异常概率并集另与同一XGBoost模型族的直接二分类结果比较。若并集的PR-AUC或Brier分数比直接模型差超过0.02，则总风险采用直接模型；染色体特异性标签仍使用三个分类器。

### 6.3 失败条件

- 任一染色体在外层测试中长期零召回；
- 测试折指标显著低于Z值规则；
- 患者级Bootstrap区间过宽且下限接近随机水平；
- 复测率超过15%仍无法满足预设灵敏度；
- 结果强依赖序号、日期或孕妇代码等泄漏特征。

触发失败条件时回退到正则化逻辑回归或只提供Z值规则与不确定性说明，不宣称机器学习优越。

## 9. 假设及依据

### 关键假设

1. **AB列是本题要求复现的筛查标签。** 依据为题面明确“以AB列为判定结果”。放宽后若获得真实核型或出生结局，必须重新训练并外部验证。
2. **同一孕妇多次检测不是独立样本。** 依据为重复采血结构。除患者级分折外，损失采用患者等权；另报告“每名孕妇随机保留一次检测”的敏感性结果。放宽为随机拆行会产生身份泄漏，因此不允许作为主结果。
3. **T13、T18、T21可同时出现。** 依据为附件存在组合标签，必须按多标签建模。

### 可放宽假设

1. 三个染色体分类器在概率并集计算中近似条件独立；用同一XGBoost模型族的直接“任一异常”二分类作敏感性对照，并按PR-AUC/Brier差0.02决定总风险来源。
2. F2所体现的漏检优先级适合筛查；用F1、Youden指数和灵敏度下限80%—90%扫描验证。
3. 15%复测率上限用于形成可执行不确定区；扫描5%—20%检查结论稳定性。
4. 训练集分位数能标记测序质量极端；同时报告题面GC 40%—60%规则，不机械删除边界样本。
