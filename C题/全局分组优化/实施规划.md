# C题问题2/3：医学小样本全局最优分组实施规划

状态：已实施并完成内部验收  
版本日期：2026-08-24

## 1. 背景与目标

现有两组和三组切点分别来自参数模型与树模型候选。树的局部贪心分裂不能证明分组全局最优；在全体OOF样本上反复试切点后再用同一OOF结果评价，也会遗漏“切点选择”带来的乐观偏差。

本阶段目标是在不改变固化数据、患者级折号和AFT预测模型基本口径的前提下，使用受约束的全局分组搜索，并把组数与切点选择完整放入嵌套验证，确定可复核的主推荐分组及稳定性边界。

## 2. 已确认要求

- 只处理 `C题/**` 与 `outputs/C题/**`。
- 不覆盖旧代码、旧报告和上一阶段对比结果，新增版本目录。
- 树两组/三组仅作为对照，不再作为“最优”的定义来源。
- 主可靠性保持 q=90%，并保留 q=85%/95%敏感性分析。
- 最小组人数保持30人；候选组数为1至4组。
- 继续使用10至25周、步长1天的推荐时间网格。
- 使用既有患者级4折外层、3折内层固定折号；外层测试折不得参与组数、切点、时点或惩罚参数选择。

## 3. 明确不做

- 不用最小P值、训练集显著性或树的重要性直接确定切点。
- 不把内部验证表述为外部医院验证。
- 不通过临时改变最小组人数、可靠性或安全容差来迎合某一方案。
- 不增加大规模黑箱模型搜索；本阶段优化对象是分组决策，不是重新竞赛预测模型。

## 4. 医学小样本方法依据

- 连续变量任意二分会损失信息和统计功效，数据驱动“最佳切点”还会产生偏倚；因此连续BMI预测保留为参照，分组只服务于题目要求的临床决策表达。
- 最大选择秩统计量适合检验单个切点，并能校正反复寻找切点的多重性，但它优化的是组间结局分离，不是本题“在可靠性约束下尽量提前检测”的决策目标，因此只作为单切点敏感性分析。
- 小样本模型开发应采用交叉验证或bootstrap内部验证；切点选择、组数选择等全部建模步骤也必须在每次重采样内重复。
- 样本有限时应限制自由度并优先选择简约方案，不能因为训练样本指标微小改善而增加组数。

## 5. 技术路线比较

| 方法 | 优点 | 主要问题 | 本阶段用途 |
|---|---|---|---|
| CART/树分裂 | 快、易解释 | 局部贪心、切点不稳定 | 仅保留历史对照 |
| 最大选择秩统计量 | 医学领域常见，可校正单切点搜索 | 主要面向结局分离，只自然支持单切点 | 两组敏感性分析 |
| 限制性立方样条/连续AFT | 保留BMI连续信息 | 不能直接交付离散分组 | 无分组性能参照 |
| 受约束全局枚举 | 能在预设候选域内证明全局最优，目标与题意一致 | 必须嵌套验证，计算量较高 | 主方法 |

## 6. 选定方案

采用“嵌套验证内受约束全局枚举 + 一标准误差简约规则 + bootstrap全流程重选”。

### 6.1 候选切点

- 将BMI从小到大排序，只允许在相邻不同BMI值的中点切分。
- 每个训练分组至少30人；若重复BMI跨越边界，则同一BMI必须在同一组。
- 枚举1、2、3、4组的全部合法连续分段，不使用树生成候选。

### 6.2 每个外层折中的开发过程

1. 仅用该外层训练集的固定内层折生成inner-OOF达标概率。
2. 对1至4组分别全局枚举合法切点。
3. 每组时点取其平均达标概率首次达到q的日期。
4. 在满足组规模、25周内达标和BMI四分位审计安全约束后，最小化人口加权平均检测孕周。
5. 把选出的切点与时点原样应用于未参与选择的外层测试折。

### 6.3 组数选择

- 先比较四个外层测试折的平均检测孕周与安全违规率。
- 只保留4/4外层折均满足安全约束的组数；若没有组数满足，则按安全违规大小排序并明确报告失败。
- 在安全组数中使用“一标准误差规则”：选择测试性能落在最佳均值一个标准误以内的最少组数。
- 最终部署切点只在组数锁定后，使用全体267人的交叉拟合概率重新全局搜索一次。

### 6.4 稳定性

- 进行1000次患者级bootstrap；每次重新执行组数和切点搜索，而不是只评价固定切点。
- 报告组数入选率、切点分布及95%区间、平均检测孕周差、安全违规率、每名孕妇分组一致率。
- 主方案需满足：组数入选率至少75%、安全合格率至少95%、所有最终组不少于30人。
- 若未达门槛，报告“无唯一稳定最优”，并给出简约主方案与稳定备选，不强行选唯一答案。

## 7. 第一指标和辅助指标

第一指标：外层测试集上满足可靠性与安全约束后的患者加权平均检测孕周。

辅助指标：

- 外层测试审计层最低达标概率及安全违规率；
- 最晚推荐孕周、组内样本量、总体达标概率；
- 相对连续个体化策略与统一时点的时间损失；
- 组数和切点bootstrap稳定性；
- q=85%/90%/95%敏感性；
- 与原参数两组、树三组、经验五组的同折对比。

## 10. 风险与回退

| 风险 | 处理 |
|---|---|
| 四组组合数量较大 | 预计算每个连续区间的时点和审计贡献，再分块枚举 |
| 外层测试某组人数很少 | 最小人数约束只在开发集判定，测试集如实报告区间与不确定性 |
| 最优切点在折间漂移 | 降低组数；报告切点区间，不用全样本单点掩盖不稳定 |
| 所有方案都违反安全约束 | 不放宽阈值；输出不可行结论并回退到统一保守时点 |
| 分组收益极小 | 优先连续模型或最少组数，避免制造虚假临床阈值 |
