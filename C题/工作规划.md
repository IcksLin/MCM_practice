# C题工作规划：数据与验证框架固化、实验归档

更新日期：2026-08-24  
当前状态：已实施并通过验收

## 1. 背景与目标

问题2/3已经形成基于区间删失 XGBoost AFT 的三组 BMI 候选方案，下一阶段将比较统一时点、两组、三组和经验五组方案，并优化可靠性参数与风险函数。在进入决策优化前，必须先固定数据版本、患者级交叉验证折号、评价口径和随机种子，避免后续方案因数据或划分变化而不可比较。

本阶段同时整理 C 题实验产物，将正式成果、可复现中间数据和已淘汰探索模型分开保存。

## 2. 已确认要求

- 只处理 C 题范围，不触碰 B 题文件和结果。
- 固化原始数据指纹、派生标签规则、训练/验证/测试折号及评价协议。
- 建立可持续更新的规划表和工作历程。
- 实验产物优先归档，不直接永久删除。
- 旧报告保留；后续报告继续追加版本，不覆盖旧版。
- 后续所有分组方案必须使用同一套外层测试折进行比较。

## 3. 范围边界

### 3.1 本阶段允许操作

- `C题/**`：新增工作框架、规划和固定折文件；不改动原始 PDF/XLSX。
- `outputs/C题/**`：整理 C 题实验产物、创建 `_archive`、保留正式结果。

### 3.2 明确不处理

- `B题/**`、`outputs/B题/**`。
- 根目录压缩包。
- 现有旧报告内容。
- Git 提交、推送和远程仓库操作。
- 下一阶段的风险函数优化和方案胜负判定。

## 4. 关键假设

- “仅在C题文件夹下”按逻辑范围解释为 `C题/**` 和 `outputs/C题/**`；不会整理其他题目。
- 原始附件 `C题/C题/附件.xlsx` 是唯一数据源，以 SHA-256 标识其冻结版本。
- 男胎问题2/3使用一名孕妇一行的区间删失标签；同孕妇同孕周的重复测量取 Y 浓度中位数。
- 女胎问题4保留记录级特征和标签，但所有折号按孕妇代码分组生成。
- 外层折承担测试角色，内层折仅用于调参和早停；最终指标只使用外层 OOF 预测。

## 5. 技术方案比较

| 方案 | 优点 | 风险 | 结论 |
|---|---|---|---|
| 每次运行重新随机划分 | 简单 | 不同方案不可公平比较 | 不采用 |
| 只固定随机种子 | 实现容易 | 库版本或排序变化仍可能改变折号 | 不足 |
| 显式保存患者级折号 | 可审计、可复用、方案可公平比较 | 需要维护折号文件 | 采用 |
| 删除淘汰模型 | 目录干净 | 丧失追溯能力 | 不采用 |
| 移动到版本化归档目录 | 可恢复、正式结果清晰 | 占用少量空间 | 采用 |

## 7. 验证框架规格

### 7.1 男胎问题2/3

- 单位：孕妇。
- 外层：4折 `StratifiedKFold`，按 left/interval/right 删失类型分层。
- 内层：每个外层训练集单独生成3折，用于 TPE 搜索和早停。
- 基准随机种子：2025；每个外层折使用显式派生种子。
- 固定字段：孕妇代码、删失上下界、删失类型、外层折号、对应内层折号。
- 禁止：测序后 QC、Z 值进入问题2/3时点模型。

### 7.2 女胎问题4

- 训练单位：检测记录；划分单位：孕妇。
- T13/T18/T21分别生成4折 `StratifiedGroupKFold`。
- 每个外层训练集分别生成3折内层分组划分。
- 同一孕妇的全部记录在任一层只能位于一个折中。
- 固定字段：样本序号、孕妇代码、标签、外层折号、对应内层折号。

### 7.3 固定评价指标

| 任务 | 第一指标 | 辅助指标 |
|---|---|---|
| 男胎达标时间 | 外层 AFT 负对数似然 | 区间一致性、区间覆盖、决策风险 |
| BMI分组方案 | 外层 OOF 预期风险 | 平均检测孕周、未达标概率、组数惩罚 |
| 女胎分类 | 患者级 PR-AUC | ROC-AUC、Brier、校准、90%灵敏度下特异度 |

## 8. 实验产物归档规则

### 8.1 保留为活跃成果

- `tree_results.json`、固定 OOF 预测和分组/敏感性 CSV。
- XGBoost AFT 最终模型。
- 入选的 T13 正则逻辑回归模型。
- 入选的 T18 CatBoost 四折模型。
- 当前报告和正式图表。

### 8.2 移入归档

- `aft_checkpoint.json`、`female_checkpoint.json`。
- T13 未入选的 CatBoost 四折模型。
- T21 的 CatBoost 四折模型和逻辑回归探索模型。
- 仅用于中断恢复、未被报告引用的临时产物。

### 8.3 归档安全要求

- 移动前计算 SHA-256。
- 只移动明确列入清单的文件，不递归清空整个目录。
- 移动后再次计算哈希，必须与原文件一致。
- 正式报告引用的文件不得移动。
- 归档清单记录原因和时间，可通过 Git 或清单恢复。

## 9. 验收标准

- 原始 PDF/XLSX 的哈希已记录且文件未变化。
- 男胎每名孕妇恰好属于一个外层测试折；每个外层训练集中恰好属于一个内层折。
- 女胎同一孕妇的所有记录在每个目标、每个层级均不跨折。
- 固定折文件重复生成时逐字节一致。
- 数据清单记录样本量：男胎1082条/267人，女胎605条/147人。
- 男胎删失统计与固化规则一致。
- 活跃模型均能成功加载。
- 归档前后哈希一致，旧报告仍存在且无内容变更。
- Git 状态中不出现 B 题相关变化。

## 10. 风险与回退方案

| 风险 | 处理方式 |
|---|---|
| 极少数右删失使分层折不均 | 固定4折并在清单中记录每折删失构成 |
| T21阳性孕妇过少 | 保留分组验证但禁止把结果解释为稳定诊断模型 |
| 文件移动破坏报告图片链接 | 报告引用的正式文件不归档 |
| 固化脚本受库版本影响 | 保存显式折号文件，不依赖未来重新随机生成 |
| 归档误移动 | 使用逐文件清单和哈希校验，不使用整目录递归删除 |
